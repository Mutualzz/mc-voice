# Contributing

PRs welcome. Redistributing unofficial builds is still not allowed — see [`LICENSE`](https://git.mutualzz.com/mutualzz/mc-voice/src/branch/master/LICENSE).

## Credit

- Your git author stays on landed commits
- Merged PRs keep your attribution
- Notable changes may appear in release notes

## How to contribute

1. Sign in to [git.mutualzz.com](https://git.mutualzz.com) with your GitHub account, then fork [this repo](https://git.mutualzz.com/mutualzz/mc-voice) and branch.
2. Keep the change focused.
3. Test with `./gradlew buildAll` (or e.g. `./gradlew :1.21.1-fabric:remapJar`).
4. Open a PR on git.mutualzz.com describing what changed and why.

GitHub is a read-only mirror — pull requests opened there are not monitored.

By contributing, you grant Mutualzz a license to use your work under the project license. You do **not** get rights to redistribute Mutualzz builds.
